# About Me

Detail-oriented Data Analyst with experience transforming raw data into actionable business insights through data cleaning, exploratory data analysis, SQL querying, dashboard development, and business intelligence reporting.

I enjoy solving real-world business problems by combining **Python, SQL, Tableau, Excel, and PostgreSQL** to build end-to-end analytics solutions that support data-driven decision making.

My experience includes:

* Cleaning, validating, and transforming large datasets
* Performing exploratory data analysis (EDA)
* Writing efficient SQL queries for business analysis
* Building interactive Tableau dashboards and KPI reports
* Developing end-to-end analytics projects using Python, SQL, and Tableau
* Presenting insights through data storytelling and visualization

I am passionate about continuous learning and enjoy building projects that mirror real-world analytics workflows—from raw data to executive dashboards.
